>_ Resume in an embedded terminal

Install Shumi

Linux / macOS

From a source checkout with Rust 1.88 or newer, run cargo run --release.

If you have a release archive, extract it and run this command from the extracted directory. Keep the executable and its sibling plugins/ directory together.

$ ./shumi-tui

Install and authenticate the CLI for each provider you want to resume. Remote hosts use OpenSSH.
